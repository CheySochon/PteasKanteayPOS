================================================================================
                    PROJECT STRUCTURE & FOLDER EXPLANATION
                     គម្រោង Thesis POS Management System
================================================================================

[1. សេចក្តីផ្តើមទូទៅ (OVERVIEW)]
--------------------------------------------------------------------------------
គម្រោងនេះជាប្រព័ន្ធគ្រប់គ្រងការលក់ (Point of Sale - POS System) ដែលត្រូវបានអភិវឌ្ឍជា
Full-stack Web Application ដោយបែងចែកជា ២ ផ្នែកធំៗ៖
1. API (Backend Server): អភិវឌ្ឍជាមួយ Node.js, Express, TypeScript, Prisma ORM (PostgreSQL), និង Socket.IO (Real-time)
2. WEB (Frontend UI): អភិវឌ្ឍជាមួយ Next.js (App Router), React 19, TypeScript, និង Tailwind CSS

[3. ព័ត៌មានបន្ថែមអំពី SYSTEM ARCHITECTURE]
--------------------------------------------------------------------------------
- Database Engine: PostgreSQL
- Authentication: JWT (JSON Web Tokens) & Password Hashing (bcrypt)
- Real-time Features: Socket.IO (ផ្សាយដំណឹងពេលមាន Order ថ្មី, ប្តូរ狀態 Order, គិតលុយរួច)
- Security & Permissions: Role-Based Access Control (RBAC) ជាមួយ Dynamic Permissions
  រក្សាទុកក្នុង Database Table `Role.permissions` (JSON) និង Cache លើ Frontend `localStorage`
- Payment Integration: Bakong KHQR QR Code Support
